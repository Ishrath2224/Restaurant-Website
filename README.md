# Restaurant Website

A visually appealing and fully responsive restaurant website developed to help restaurants establish a strong online presence. The website highlights menu offerings, restaurant information, customer reviews, and reservation/contact details while delivering an engaging user experience.

## Features

* Responsive and mobile-friendly design
* Interactive food menu section
* About Us and restaurant story section
* Customer testimonials and reviews
* Contact and reservation information
* Modern layout focused on user engagement

## Tech Stack

* HTML
* CSS
* JavaScript
* React

## Objective

The purpose of this project was to design a professional restaurant website that enhances customer engagement, improves accessibility to menu information, and strengthens the restaurant's digital presence.
